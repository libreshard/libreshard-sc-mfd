Control profile

The buttons use the default keys of SC 4.10. Actions with no default key (doors, shields, operator modes, emotes…) are bound by the LibreShard MFD profile:

  1. Copy LibreShard_MFD.xml (in this shard's folder) to StarCitizen\LIVE\user\client\0\controls\mappings.
  2. In the game: Options → Keybindings → Control Profiles → LibreShard MFD.
